# Dead Zone — Downloads

Official public Windows releases for Dead Zone. No GitHub account is required to download.

## Download the game

[Dead Zone Alpha 0.1.3 — Co-op Hotfix](https://github.com/miagond/dead-zone-releases/releases/tag/dead-zone-0.1.3-coop-hotfix)

Open the release and download **Dead-Zone-Alpha-0.1.3-Coop-Hotfix-Windows.zip** under Assets. Extract all files before launching.

## Auvendra launcher

The native Auvendra launcher is being prepared with game installation and automatic launcher updates. Preview releases are not automatically installed as stable updates.

## What is in this repository?

Release downloads and documentation only. Game and launcher source code are not uploaded here. The automatically generated “Source code” archives contain repository documentation, not the game source.

Only the owner and explicitly authorized collaborators can modify this repository. Public visitors can download releases.
